## Part 3
### Message Storage and Reporting
* Part 3 expands the messaging system by adding message storage, searching, deletion, and reporting features.
  
### Stored Messages
* Messages can be stored and managed during application runtime.
* Stored messages can be displayed through the Stored Messages menu.
* The application can display the longest stored message entered by the user.

### Message Searching
* Users can search for messages using:
* Message ID
* Recipient cellphone number
* The system will display all matching messages based on the selected search option.

### Message Deletion
* Stored or sent messages can be deleted using their unique Message Hash.
* Once deleted, the message is removed from the application's tracking arrays.

### Message Reporting
* The application can generate a report containing:
* Message Hash
* Recipient Number
* Message Contents
* Enables the reviewing of all sent messages.

- - -

### How to Run the Program
* Open the project in NetBeans or any Java IDE.
* Compile all Java files.
* Run MainApp.java.
* Register a new user.
* Log into the application.
* Use the Chat App Menu to send, store, search, delete, and report messages.
