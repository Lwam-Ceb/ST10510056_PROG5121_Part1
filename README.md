## Features
### Username Validation
* This feature will review the username you enter and will accept or deny it based on if your username has an "_" and is 5 words or less.
  
### Password Validation
* This password feature will review and validate the password given based on if said password has a special letter, a capital letter and a number. This password must be at least 8 letters long.

### Phone Number Validation
* This cellphone number feature will review the number thats being added to your account. Your number will have to be 12 characters long and will have to start with "+27".

### User Registration
* This feature will combine the valid user information provided to register you into the system allowing you to text on this chat application.
